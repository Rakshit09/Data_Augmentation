# Sample Flood Hazard Layer

Downloaded from the official Land NRW / LANUV WMS service.

- Source service: `https://www.wms.nrw.de/umwelt/wasser/HW_Gefahrenkarte`
- Service title: `WMS Hochwasser-Gefahrenkarte NRW`
- Sample area: Cologne/Bonn area, NRW, Germany
- CRS: `CRS:84` / lon-lat WGS84
- Bounding box: `6.80,50.80,7.25,51.10`
- Scenario: `Mittlere Wahrscheinlichkeit (HQ100)`
- Layers: `Tiefen_Ueberflutungsgebiet_mw,Grenze_der_ueberfluteten_Gebiete_mw`
- Attribution/license note from service capabilities: Open Data, Datenlizenz Deutschland Namensnennung 2.0; use source attribution `Land NRW`.

Files:

- `nrw_flood_hazard_hq100_cologne_sample.png`: quick preview image.
- `nrw_flood_hazard_hq100_cologne_sample.tif`: georeferenced GeoTIFF sample for direct upload.
- `nrw_flood_hazard_hq100_cologne_sample.tfw`: world file kept for provenance; the GeoTIFF already has embedded georeferencing.
- `nrw_flood_hazard_hq100_cologne_sample.prj`: WGS84 projection sidecar.
- `nrw_flood_hazard_hq100_legend.png`: official legend for the water-depth layer.
- `nrw_flood_hazard_wms_capabilities.xml`: hazard WMS capabilities document.
- `nrw_flood_risk_wms_capabilities.xml`: risk WMS capabilities document.
