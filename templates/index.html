Critical note

Do not run the application from your local desktop if the Parquet or DuckDB files are stored on the J: drive. This will not work reliably.

Either use the Analytics Desktop environment or move the Parquet and DuckDB files to a local drive before running the application.

If using Analytics Desktop, first copy the DuckDB and Parquet files from the J: drive into the etl_output folder inside the application directory.
